# **Guide d’installation**

### Prérequis

- Node.js 18.x ou supérieur
- pnpm
- Compte Supabase

### Étapes d'installation

1. **Cloner le dépôt**
2. **Installer les dépendances**

```bash
pnpm i
```

1. **Configurer Supabase**

- Créer un nouveau projet sur Supabase
- Exécuter les scripts SQL suivants dans l'éditeur SQL de Supabase :

```sql
create table public.role (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  name text null,
  constraint role_pkey primary key (id)
) TABLESPACE pg_default;

create table public.profile (
  id uuid not null,
  created_at timestamp with time zone not null default now(),
  firstname text not null,
  lastname text not null,
  active boolean not null default true,
  role bigint null default '2'::bigint,
  constraint user_pkey primary key (id),
  constraint user_data_role_fkey foreign KEY (role) references role (id) on delete set null,
  constraint user_id_fkey foreign KEY (id) references auth.users (id) on delete CASCADE
) TABLESPACE pg_default;

create table public.information_category (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  title text null,
  constraint information_category_pkey primary key (id)
) TABLESPACE pg_default;

create table public.information (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  title text null,
  content text null,
  url text null,
  image text null,
  category bigint null,
  constraint information_pkey primary key (id),
  constraint information_category_fkey foreign KEY (category) references information_category (id) on update CASCADE
) TABLESPACE pg_default;

create table public.respiration (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  inspiration bigint not null,
  apnea bigint not null,
  expiration bigint not null,
  constraint respiration_pkey primary key (id)
) TABLESPACE pg_default;

create table public.diagnostic_event (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  title text null,
  points bigint null,
  constraint diagnostic_event_pkey primary key (id)
) TABLESPACE pg_default;
```

1. **Configurer les variables d'environnement**

Créer un fichier `.env` à la racine du projet avec les variables suivantes :

```bash
NEXT_PUBLIC_SUPABASE_URL= #Remplir avec le lien donné par Supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY= #Remplir avec la clé donnée par Supabase
```

1. **Lancer l'application en développement**

```bash
pnpm dev
```

1. **Accéder à l'application**

Ouvrez votre navigateur à l'adresse [http://localhost:3000](http://localhost:3000/)

1. **Tester l’application avec Jest**

```bash
pnpm jest
```
